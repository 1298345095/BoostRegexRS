# 提供原生 Rust 接口并保留输入位置单位

现有 `boost-regex-sys` 只暴露部分能力，因此新库重新设计完整、符合 Rust 使用习惯的公开接口，而不以保留现有封装接口为约束。普通调用者通过安全 Rust API 使用；必要的平台调用封装在内部。实际适配现有程序暂缓，当前交付范围为独立库及其文档和验收。

匹配范围与错误位置按原始输入单元计数：字节和 UTF-8 输入使用字节偏移，UTF-16 使用 16 位单元偏移，UTF-32 使用 32 位单元偏移。匹配与捕获的范围采用左闭右开区间。

字节接口接受任意字节，不强制转换为有效 UTF-8；Unicode 接口与字节接口的行为需明确区分。此约定保留现有调用方的原始字节能力，也避免将编码转换后的内部位置泄漏为外部位置。

内置字符规则下，编译后的正则支持跨线程安全共享，每次匹配独立维护执行状态。自定义字符规则只有满足线程安全条件时才允许跨线程共享，同时保留单线程自定义规则的使用方式。
