## Reproduce the backlog audit

```sh
python3 -B tools/dev/ticket_backlog.py check
python3 -B tools/dev/ticket_backlog.py render
```

The audit rejects missing/duplicate IDs, unknown or cyclic dependencies, unresolved dependency names, unowned capability rows and tickets that cannot reach the final acceptance gate. Publication IDs are recorded in `published.json`; it also verifies that blocker issues were created first and their exact rendered UTF-8 body hashes still match. [Coverage](coverage.md) maps all 406 rows without changing their prior status.

Each ticket includes the checkpoint state, source contracts, implementation and independent verification deliverables, binary acceptance criteria and a bounded scope. Broad input migration uses expand, per-encoding migration, then contract. If a new mechanism is discovered beyond a ticket's bounded scope, add a linked follow-up before closure; never drop the remaining requirement.
